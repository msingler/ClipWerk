Privacy Policy

Last updated: 18. November 2026 / November 18, 2026

1. Summary

ClipWerk runs entirely on the developer's own computer. It has no server, no user database, no analytics, no advertising and no tracking. No data is sold or shared with third parties.

2. Data accessed from TikTok

With the account owner's explicit authorization via TikTok Login Kit, ClipWerk uses these scopes:

  • user.info.basic – display name, to show which account is connected.
  • video.upload – to send edited videos as drafts to the account owner's TikTok inbox.
  • video.list – to read view counts of the owner's own videos for personal statistics.

3. Storage

The TikTok access token and the statistics are stored only locally on the developer's computer. The token is encrypted with Windows Data Protection (DPAPI) so that only the logged-in Windows user can read it. Nothing is transmitted anywhere except directly to TikTok's official API (and Twitch's official API to find public clips).

4. Deletion

Disconnecting ClipWerk in its settings deletes the stored token. Access can also be revoked in the TikTok app under Settings → Security → Apps and services. Deleting the program folder removes all locally stored data.

5. Children

ClipWerk is not directed at children and is used only by its adult developer.
